# DUALIS ArtLab Context

Proyecto: DUALIS

Inspiración estructural:
- Head Over Heels (1987)
- No copiar mapas, gráficos ni personajes.
- Sí copiar claridad visual, lectura inmediata y diseño de puzzles.

Motor:
- Python
- Vista isométrica
- Rooms conectadas
- UNO y DOS siempre presentes
- Cooperación espacial permanente

Dirección artística:
- Isométrico clásico tipo Head Over Heels
- Más atmosférico y moderno
- Siluetas muy legibles
- Pocas piezas reutilizables
- Sin realismo

Regiones actuales:
- R1 Vestíbulo (piedra)
- R2 Biblioteca (papel/tinta)
- R3 Taller (cobre)
- R4 Jardín Invertido (musgo/lila)
- R5 Torre de los Nombres (alabastro/tinta)

Objetivo:
Diseñar pipeline gráfico, assets, herramientas, sprites, tiles y referencias visuales para DUALIS.
